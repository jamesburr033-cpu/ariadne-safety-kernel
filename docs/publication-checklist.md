# Publication Checklist

Before publishing:

- Confirm no PHI.
- Confirm no employer-confidential content.
- Confirm no Epic/SMMC/internal workflow details.
- Confirm no screenshots from work systems.
- Confirm no .env files.
- Confirm no API keys or tokens.
- Confirm no local secrets.
- Confirm no private paths.
- Run secret scanning.
- Use synthetic examples only.
- Publish a clean repo, not a scrubbed copy of a private working repo.
